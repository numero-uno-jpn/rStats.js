## 見つけた不具合: プロファイルの制約つき当てはめが最後の ulp で往復する

binomial `glm(1:6, c(0, 0, 1, 0, 1, 1))` の Rao の 95% 区間は、切片の上限が NaN だった。R は 0.6603 (スプライン)。90% 区間では傾きの下限が NaN になった。

- 原因: glmConfint の制約つき当てはめは、係数が止まるまで反復する (`untilCoefficients`: 変化が 8 ε × max|係数| 以下)。
  - 固定した係数が大きく、残りの係数が 0 に近いとき (0.005 など)、係数は最後の数 ulp で 2〜5 個の値を回り続ける。往復の大きさ 1e-16〜4e-16 は作業応答の丸めから来るもので、8 ε × 0.005 より大きい。
  - そのため maxit (100) まで回って未収束と判定され、区間の端が NaN になっていた。
- 61 回目より前のコード (`4df26fb`) でも同じ値だった。61・62 回目の修正が原因ではない。
- 修正: 今の係数が直前 16 回のどれかと全成分で厳密に一致したら (周期)、収束とする。これまで未収束で終わっていた場合にしか働かない。
- 修正後の切片の上限は 0.67093。R 自身のプロファイルの点 (切片 0.66 で z = 1.9527、0.8 で 2.0478) を線形補間しても 0.6707 で、R の 0.6603 はスプライン補間の誤差。

## 修正の内容

- `src/models/glm.ts` (irls、`untilCoefficients` のとき): 直前 16 回の係数と一致したら収束 (周期の検出)
- `src/models/glmAnova.ts`: 比較するモデルが未収束なら警告 "model k has not converged: its deviance is not that of the maximum likelihood fit"
