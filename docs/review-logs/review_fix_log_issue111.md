# Issue #111 対応ログ: dweibull の log(shape/scale) が、形状と尺度がほぼ等しいとき比の丸めを受ける

GitHub Issue #111。R も同じずれ (R が不正確な場合)。計画は承認済み (テストの参照値を Rmpfr に変えた)。

## 確認 (main `f8bcd0f`)

`src/distributions/weibull.ts` の `logRatio(a, b)` は Math.log(a/b)。a/b ≈ 1 では比の丸め (絶対 ε/2) がそのまま log の値の誤差になり、log の値が小さいので相対誤差が大きい。issue の指摘どおり。

| 呼び出し | 真値 (正しく丸めた値) | R 4.5.2 | 修正前 | 修正後 |
|---|---|---|---|---|
| dweibull(2^52 − 0.5, 2^52, scale = 2^52 − 0.5, log) | −0.9999999999999999 | −0.99999999999999982 | −0.9999999999999998 | −0.9999999999999999 |

## 修正

|a − b| ≤ 2^-20 b なら Math.log1p((a − b)/b) (a − b は Sterbenz の補題で厳密、丸めは割り算の 1 回)。それ以外は R と同じ式で、通常の形状 (0.5、1.5、2、3 など) の値は 1 ビットも変わらない。docs (英・日) の「R が不正確な場合」(分布) に 1 行。
