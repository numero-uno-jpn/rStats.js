# Issue #16・#17 対応ログ: cor の対角と quantile の欠測の確率 (変更なし、R と同じ)

GitHub Issue #16 (監査ラウンド #74)・#17 (#75)。どちらもレビュアーが「R と違う」とした指摘だが、R 4.5.2 で確かめると R と同じ動きだった。コードは変えていない。

## #16 cor の対角

| 入力 | rStats.js | R 4.5.2 |
|---|---|---|
| `cor([[1, 1], [1, 2], [1, 3]])` (1 列目が定数) | [[1, NaN], [NaN, 1]] | [[1, NA], [NA, 1]] |
| `cor([[1, 2], [NaN, 3], [3, 4]], use = "everything")` | [[1, NaN], [NaN, 1]] | [[1, NA], [NA, 1]] |
| spearman で 1 列目が定数 | [[1, NaN], [NaN, 1]] | [[1, NA], [NA, 1]] |

レビュアーの「R は対角に NA を返す」は誤り。定数の列の自分自身との相関は 0/0 で定義できないが、R は慣例として対角を 1 にしている。非対角が NaN になるので、問題は利用者に伝わる。オーナーの判断: R のまま。

**追記 (Issue #78、2026-11-02):** オーナーの判断で覆した。定義されない対角は NaN にする (R と違う、`review_fix_log_issue78.md`)。`test/issue16_17.test.ts` の #16 の期待値も変えた。

## #17 quantile の確率 NaN

`quantile([1, 2, 3], [0.25, NaN, 0.75])` は [1.5, NaN, 2.5]。R 4.5.2 の `quantile(c(1, 2, 3), probs = c(0.25, NA, 0.75))` も 1.5、NA、2.5 を返し、エラーにならない。レビュアーの「R はエラー」は誤り。変えない。
