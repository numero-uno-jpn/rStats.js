# Issue #32 対応ログ: df で df1 < 2、df2 が巨大なときの分母の溢れ (再現しない、変更なし)

GitHub Issue #32。

## 確認 (main `0faef4e`)

| 入力 | rStats.js | R 4.5.2 / 極限 |
|---|---|---|
| `df(1, 1, 1e308)` | 0.24197072451914498 | 0.2419707245191434 (R)。極限 exp(−1/2)/sqrt(2π) = 0.24197072451914337 |
| `df(1, 1.5, 1e308)` | 0.3106642581377729 | 0.3106642581377688 |
| `df(2e4, 1, 1.7e308, log)` | −10005.870682309473 | カイ二乗の極限 −10005.870682309473 |

0 にはならない。

## 理由

レビュアーが指摘した式 `((m / (n + m x)) m n) / (2 (m + n) p)` は、`fDensity` の df1 < 2 の枝にあるが、その直前に `Math.min(m, n) / 2 < SMALL_SHAPE` (SMALL_SHAPE = 1) なら対数の密度 (`fLogDensity`) で計算する分岐がある。df1 < 2 では min/2 < 1 なので、必ずこちらを通り、指摘の式には届かない (レビュアーは「min(m, n)/2 = 0.5 なので小さな shape の枝に入らない」と読んだが、閾値は 1)。

指摘の式を含む df1 < 2 の枝は、通らないコードになっている。今回は変えていない (指示されていない変更のため)。
