## 修正 (ユーザー判断: 提案どおり)

- **NBINOM-NEW-02 `fromMu`:** size + mu が溢れるときは、小さい方 / 大きい方の比 r から 1/(1+r) と r/(1+r) を double-double で求める
- **HYPER-NEW-01:** k/(m+n) < 2^-60 (m·2^-60 + n·2^-60 と比べる) のとき、d/p/q を二項分布 Bin(k, m/(m+n)) で計算する。m/(m+n) は和を作らずに `whiteFraction` で求める。相対誤差は k/N 程度で、倍精度では区別できない
- **rhyper:** k = 1 の rbinom の確率を `whiteFraction` にした。k > 1 は従来どおり一様乱数 1 個で qhyper を引く (乱数の消費は R と同じ)

## 対応しなかったもの

- RT-NEW-01、NBINOM-NEW-03: 修正済み (`e229621`、`2514938`)
- HYPER-NEW-02、INTEGER-NEW-01: 整数の精度 (2^53) を超える領域。NaN を返す
- GEOM-REVIEW-03、RPOIS-REVIEW-01、IBETA-REVIEW-03、GEOM-REVIEW-02: 誤答の具体例なし、またはレビュアー自身が問題なしと判定
