## そのほかの修正

- **LMER-NEW-01 (lmer の Jacobi 法):** 要素が 1e200 程度だと二乗和が Inf になり、`Inf <= 1e-32 Inf` で回転せずに終わっていた。極端な大きさの行列は 2 の冪で正規化してから分解し、固有値を戻す
- **LMER-NEW-03 (入れ子でない当てはめの LRT、ユーザー判断で統計学的に正しい方向):** 小さい当てはめの固定効果の列名がすべて大きい当てはめにあり、ランダム効果の各項が大きい当てはめの同じグループの項に含まれる場合だけ、Chisq と p 値を出す。それ以外は NaN (AIC・BIC は出す)。lme4 の fixture の `(1 | g)` と `(1 | h)` (自由度の差 0、lme4 は Chisq 0、p NaN) は、テストで意図的な差として扱った

## 対応しなかったもの

- LMER-NEW-02 (Hessian の閾値 1e-8): lmerTest と同じ。既知の残作業 (No.120)
- COX-NEW-04、NT-NEW-01/02、NCHISQ-NEW-01/02、NBETA-NEW-01: 誤答の具体例なし (積分・探索の未収束を通知しない、という設計上の指摘)
