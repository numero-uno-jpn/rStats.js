# Issue #47 対応ログ: propTest の整数でない計数 (判定のみ、コード変更なし)

GitHub Issue #47。ユーザー判断で R のままにする (not planned)。

## 確認 (main `6c6a38d`、R 4.5.2)

issue は「R の prop.test は、有限の計数がすべて整数であることを求める」としている。R のヘルプには "should be integers" とあるが、R 4.5.2 の `prop.test` のソースには整数の検査がない (`n <= 0`、`x < 0`、`x > n` だけ)。issue の 3 例は、R でも結果を返す (警告 "Chi-squared approximation may be incorrect" は期待度数が小さいため)。

| 呼び出し | R 4.5.2 (統計量、p、推定値、区間) | rStats.js |
|---|---|---|
| `propTest(1.5, 3.5)` | 0、1、0.428571428571428559、[0.077319428297977568, 0.861682013524786328] | 0、1、0.42857142857142855、[0.0773194282979775, 0.8616820135247863] |
| `propTest([1.5, 2.5], [3.5, 4.5])` | 2.5e-32、1、(0.4286, 0.5556)、[−0.94647800485498141, 0.69250975088672746] | 0、1、同じ、[−0.9464780048549815, 0.6925097508867275] |
| `propTest([[1.5, 2], [2, 2.5]])` | 0、1、(0.4286, 0.4444)、[−0.72425578263275909, 0.69250975088672746] | 0、1、同じ、[−0.7242557826327591, 0.6925097508867275] |

rStats.js は R と一致している (2 例目の統計量 0 は、R の丸めの残り 2.5e-32 を 0 にしたもの。docs に記録済み)。

## 判定

変更なし (ユーザー判断)。統計量は chisqTest の分割表と同じ Pearson の χ² で、chisqTest も (R と同じく) 小数の度数を受け付ける (重み付きの度数など)。誤った値になる具体例はない。整数を求める binomTest (R の binom.test も拒否する) とは扱いが分かれるが、R と同じ。
