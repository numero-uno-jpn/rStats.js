# Issue #25 対応ログ: dcauchy の π·scale の溢れ

GitHub Issue #25 (監査ラウンド #98)。計画は承認済み。

## 再現 (main `272eb5a`)

| 入力 | rStats.js (修正前) | R 4.5.2 | 修正後 | 対数の密度の exp |
|---|---|---|---|---|
| `dcauchy(1.1e308, { scale: 1e308 })` (\|z\| > 1) | 0 | 0 | 1.44031622707598e-309 | 1.440316227076037e-309 |
| `dcauchy(0.5e308, { scale: 1e308 })` (\|z\| ≤ 1) | 0 | 0 | 2.546479089470323e-309 | 2.546479089470145e-309 |
| `dcauchy(5, { scale: 1e308 })` | 0 | ― | 3.183098861837906e-309 | 3.183098861837817e-309 |

違いは非正規化数の精度 (2^-1074 ≈ 5e-324 の単位) の範囲。

## 原因と修正

scale が 5.7e307 (最大の double / π) を超えると、線形の密度で π × scale が溢れて Inf になり、密度が 0 になっていた。Issue の例 (|z| > 1) だけでなく、|z| ≤ 1 の枝と、x − location が溢れる枝も同じだった。対数の密度は正しかった。

`src/distributions/cauchy.ts` (`dcauchy1`): 3 つの線形の枝で、π × scale が有限なら今の式のまま (同じビット)、溢れるときだけ 1/π を先に計算する (`overPiScale` と、|z| ≤ 1 の枝の同じ判定)。

## テスト

- `test/issue25.test.ts`: 4 例 (3 つの枝) が、対数の密度の exp と非正規化数の精度で一致する。ふつうの scale は今と同じ
- stash で、修正前に失敗することを確かめた
