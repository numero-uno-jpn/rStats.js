# Issue #88 対応ログ: lmer の完全適合の判定と大きなオフセット (再現しない)

GitHub Issue #88。判定: 再現しない (not planned)。コードの変更なし。

## 確認 (main `fc1bfcf`)

issue の主張: `lmerWithCriterion` の完全適合の判定 `ycMax <= EXACT_FIT * maxAbs(original.y)` が `EXACT_FIT = 1e-12` で粗く、1e12 のオフセットを持つ応答 (残差 0.5 程度) を完全適合として拒否する。

今のコード (`src/models/lmer.ts` 226 行) は `EXACT_FIT = 16 * Number.EPSILON` (約 3.6e-15) で、1e-12 ではない。Issue #12 で同じ問題 (大きな定数を足した応答が完全適合として拒否される) を直したときに変えてある (`c3d8d71`、2026-11-01)。レビュアーは修正前のソースを見ていたと思われる (#67 と同じ)。

issue の例 `lmer("y ~ 1 + (1 | g)", ...)` を実行した結果:

| 応答 | 結果 |
|---|---|
| 偏差 (0, 0.5, −0.5, 0.25, 0.75, −0.25) | sigma 0.46770717334674267、theta 0 |
| 1e12 + 同じ偏差 (issue の例) | sigma 0.46770717334674267、theta 0 (エラーにならない) |

閾値は 1e12 × 3.6e-15 = 3.6e-3 で、残差 0.5 より十分小さい。

## 判定

修正済み。変えない。
