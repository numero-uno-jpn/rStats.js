- `src/internal/discrete.ts` `discreteQuantile`: 上への探索で `good` が Infinity になり、hi が Infinity のときは、`Number.MAX_VALUE` で条件を確かめる。満たせばそこまでを二分法で探し、満たさなければ今と同じく hi を返す。hi が有限のときは、ループの条件で抜けて hi までを二分法で探す (修正前はすぐに hi を返していた。到達するのは hi が 9e307 を超える場合だけ)。溢れない範囲の動きは変わらない
