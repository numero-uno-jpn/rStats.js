# 外部レビュー (19 回目) 対応ログ

レポート: ユーザーがチャットに貼り付けた追加監査 (乱数の状態の復元・多項分布、Gamma 乱数、連続分布の乱数、超幾何・Wilcoxon の乱数)。レビュアーは push 前のコードを見ていて、MT の状態の検証 (`6f45046`)、rmultinom の size (`2dcd910`)、rtriang (`2dcd910`)、rhyper (`579e44c`)、rsignrank・rwilcox (`6f45046`) は修正済み。rbits の指摘はレビュアー自身が撤回した。

## R 4.5.2 で実行して確かめた結果 (set.seed(1) のあとの値と、次の runif(1))

| `rgamma(1, -1, scale = 0)` | 0 (乱数を引かない) | 0 | **修正 (ユーザー判断)**: NaN。乱数は引かないので、次は R と同じ 0.2655086631421 |

| MT の状態語が 2^40 | — | `>>> 0` で 2^32 の剰余に丸めていた | **修正**: 32 ビット整数でなければエラー |
