# 外部レビュー (20 回目) 対応ログ

レポート: ユーザーがチャットに貼り付けた追加監査 (Beta・Poisson 乱数、非心 F・二項乱数、乱数ストリームと状態)。

## R 4.5.2 で実行して確かめた結果 (set.seed(1) のあと)

| 項目 | R 4.5.2 | rStats.js (修正前) | 対応 |
|---|---|---|---|
| `rbeta(4, 0, 0, ncp = 0)` | NaN×4 (乱数を引かない)、次 0.2655 | 同じ | **修正 (ユーザー判断 (a))**: 0 か 1 (Beta(0, 0))。乱数を 1 個引くので、ここだけ R と乱数の状態がずれる |
| `rbeta(4, 0, 0)` | 0 0 1 1 | 同じ | 一致 |
| `rbeta(3, 1e308, 1e308)` | 0 0 0 (1 個につき一様乱数 2 個)、次 0.944675268605351 | 同じ | **修正**: 0.5 (平均)。一様乱数は 2 個ずつ引くので、次は R と同じ |
| `rbinom(2, 2147483646 / 2147483647 / 2147483648, 0.5)` | 3 通りの値と次の乱数 | 完全に一致 | 対応不要 |
| `parallel::nextRNGStream(c(7L, …))` | 受け付ける | 受け付ける | **修正**: 10407 と 407 だけ (setRandomSeed が復元できるもの) |

## 対応しなかったもの

- RF-NEW-01、MT-NEW-01: 修正済み (`6f45046`、`65241e5`)
- RPOIS-NEW-01、RNCHISQ-REVIEW-01: 2^53 による数値表現の制約 (R も同じ)
- RNG-REVIEW-01 (正規乱数のキャッシュ): レビュアーも問題なしと判定
