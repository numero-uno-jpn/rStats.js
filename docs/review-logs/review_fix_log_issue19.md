# Issue #19 対応ログ: distSummary の退化した超幾何分布でモーメントが NaN

GitHub Issue #19 (監査ラウンド #77)。計画は承認済み。

## 再現 (main `8331905`)

| (m, n, k) | rStats.js (修正前) | 修正後 |
|---|---|---|
| (0, 1, 0) | 平均 0、分散 NaN | 平均 0、分散 0 |
| (0, 0, 0) | 平均 NaN、分散 NaN | 平均 0、分散 0 |
| (1, 0, 1) | 平均 1、分散 NaN (レビュアーの例にはない) | 平均 1、分散 0 |

標準偏差も同じ。中央値と最頻値は修正前から正しかった。この関数に対応する R の関数はない。

## 原因と修正

母集団の大きさ N = m + n が 0 か 1 のとき、平均 k m / N と分散の (N − 1) での割り算が 0/0 になっていた。

`src/distributions/summary.ts` (hyper): 1 点分布 (k = 0、m = 0、n = 0、k = N) では分散を 0 とし、平均は N = 0 なら 0 とした。N ≥ 2 の 1 点分布では、今の式も 0 だった (同じ値)。歪度と尖度は今まで通り NaN。
