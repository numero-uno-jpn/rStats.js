# Issue #12 対応ログ: lmer の応答に大きな定数を足すと「完全に当てはまる」と誤ってエラー

GitHub Issue #12 (監査ラウンド #69)。計画は承認済み。

## 再現 (main `fc39dc5`)

`lmer("y ~ 1 + (1 | g)", ...)`、y = c + (0, 20, 40, 60, 100, 120, 140, 160, 180)、3 群。

| c | rStats.js (修正前) | R 4.5.2 + lme4 2.0.6 | 修正後 |
|---|---|---|---|
| 0・1e12・1e14・1e15 | 正しい (切片 − c = 91.11、σ 24.037) | 1e15 で切片 − c = 93 (収束の警告) | 同じ |
| 1e16 | エラー "the response is fitted exactly by the fixed effects" | 切片 − c = 92、σ 23.14 (収束の警告) | 切片 − c = 92 (c + 91.11 の 1 ulp = 2 の丸め)、σ 24.037 (もとのデータと同じ) |

1e16 の隣り合う double の間隔は 2 なので、20 刻みの値は区別できる。

## 原因と修正

完全に当てはまるかの判定は、y − X β₀ の最大の絶対値が 64ε × max|y| 以下かどうか。1e16 では閾値が 142 で、残差 (約 90 = 40 ulp) より大きかった。

`src/models/lmer.ts`: `EXACT_FIT` を 16ε にした (1e16 で 35.5)。本当に完全に当てはまる応答の丸めの残り (数 ulp) は、今まで通りエラーになる (既存の section 4 のテストと、1e16 の定数の応答で確かめた)。

## テスト

- `test/issue12.test.ts`: c = 1e12・1e14・1e15・1e16 で、切片 − c がもとのデータの切片と c の 1 ulp 以内、σ と分散成分が相対 1e-12 で一致する。定数の応答 (5 と 1e16) はエラーのまま
