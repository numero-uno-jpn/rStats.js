# 精度

[English](../accuracy.md) | 日本語

> この文書は [英語版](../accuracy.md) の訳です。内容が食い違うときは英語版が正です。

公開しているすべての関数を R 4.5.2 と照合してテストしています (R にない `erf` と `erfc` は mpmath と照合)。期待値は [`oracle/`](../../oracle) の R スクリプトで生成し、[`test/fixtures/`](../../test/fixtures) に保存しています (1 ケースにつき JSON 1 行)。そのため、テストの実行に R は要りません。テストの入力には必ず、典型的な値、遠い裾 (p = 1e-300)、境界 (0, 1, df → ∞)、NaN と Infinity、負の値、巨大なパラメータを含めています。

## ケースが合格する条件

1. 下記の許容誤差の範囲で **R と一致する**。または
2. 同じ許容誤差の範囲で **高精度の参照値と一致する** (256〜1300 ビットの Rmpfr、または gmp による厳密な有理数)。この場合は R 自身が誤っており、テストの出力では「R より正確」として数えます。または
3. 分位点関数では、**後退誤差が R 以下である**。つまり、rStats.js の答えで評価した分布関数の値が、R の答えで評価した値と同じくらい p に近いことです。分布関数が平坦なところでは分位点関数の条件数が大きく、p のわずかな違いが答えの大きな違いになるため、そこで相対誤差を比べても意味がありません。離散分布では、答えは定義を満たす最小の整数でなければならず、これを分布関数で確かめます。

rStats.js が意図して R と異なるケースは、テストファイルで理由を書いたうえで除外し (`knownDifference`)、[differences-from-r.md](differences-from-r.md) に載せています。テストの出力は、フィクスチャごとに、R と一致したケース、参照値と一致したケース、後退誤差で合格したケース、除外したケースの数を報告します。

比較の詳細は次のとおりです。

- 期待値が非正規化数 (< 2^-1022) のときは、絶対誤差 1e-14 × 2^-1022 まで許容します。
- 0 に近い対数密度と対数確率は |差| / max(|期待値|, 1) で測ります。対数スケールでは 0 付近の値に特別な意味がないためです。

### 参照値

- **分布:** 参照値はすべてのケースについて計算するわけではありません (時間がかかりすぎるため)。R との比較で不合格になったケースだけを書き出して計算し、結果を `test/fixtures/<name>.ref.json` に保存します (`npm run refresh-references`)。各 oracle は `write_fixture(..., ref = function(row) ...)` で参照値の関数を登録します。`pnbinom` の 4 件は、Rmpfr の参照値が誤っているか得られないため、代わりに mpmath (60 桁、`betainc`) で計算しました: 両側の `pnbinom(1e8, 2.5, mu = 1e6)` (Rmpfr は p = size/(size + mu) を 256 ビットで作ってから 1 − (反対側の裾) を取るため、8e-106 という結果には雑音しか残りません)、`pnbinom(300, 50, 0.3, lower.tail = FALSE)`、`pnbinom(30, 3, 1 - 1e-10, log.p = TRUE)`。`nbinom` について `npm run refresh-references` をやり直すと、最初のものは誤った Rmpfr の値に戻ってしまいます。非心分布では、ポアソン混合級数の和または数値積分を Rmpfr で計算します (`oracle/_noncentral.R`)。実用的な時間で参照値を計算できない領域 (df = 1000 または 1e5 の非心 t、df2 = 1e9 かつ x > 30 の非心 F) はグリッドから外しています。
- **仮説検定:** oracle はすべてのケースについて参照値をフィクスチャの `reference` フィールドに保存します。高精度が必要なのは平均、分散、相関係数だけなので、これは速く済みます。t 検定では、分散と標準誤差を Rmpfr (256 ビット) で計算しますが、平均は先に double へ丸めます。R も rStats.js も、`estimate` に出力する丸めた平均の差を使うためです。そのうえで p 値と分位点は R の `pt`/`qt` から求めます。Fisher の r × c 検定はすべての表を列挙し、gmp で厳密に合計します。Kendall の正確検定は Rmpfr (1024 ビット) で反転数を数えます。
- **0.6.1 で追加した特殊関数** (`choose`、`lchoose`、`factorial`、`lfactorial`、`digamma`、`trigamma`、`psigamma`、ベッセル関数、`dmultinom`、および R にない `gammainc`、`erfinv`、`erfcinv`、`perm`。これら 4 つの R のフィクスチャは `pgamma` × `gamma`、pracma の定義、Rmpfr で計算します): R のフィクスチャに加えて mpmath とも照合します (`scripts/mpmath/*.py`、60〜800 桁、`test/fixtures/<name>.mpmath.json`)。許容誤差は同じ 1e-14 です (`erfinv`、`erfcinv`、`perm` は 1e-15)。mpmath の値は数学的な関数なので、この照合では `rCompatible: false` を使います。R が不正確な点や失敗する点の参照値 (`<name>.ref.json`) は、Rmpfr ではなく mpmath (100〜800 桁、引数は倍精度の値) で計算しました。項が打ち消し合う箇所 (x < 0 の digamma と psigamma、振動する領域の J と Y、負の非整数次数の I) では、打ち消し合う項の大きさ (フィクスチャの `scale`) に対する相対誤差で測ります。x < 0 の `psigamma` は 2e-14 まで許します。反射項が cot(pi x) の deriv + 1 次の多項式で、cot の誤差を最大 101 倍にするためです (R との照合でも同じ)。`besselJ` と `besselY` の R との照合では、答えが打ち消し合う項よりはるかに小さいケースは、mpmath の値との差が `scale` に対して 1e-14 以内なら合格とします (`knownDifference`)。そこでは相対誤差で見ると R のほうが近いためです。
- **log1p 系の関数** (`log1pmx`、`lgamma1p`、`log1mexp`、`log1pexp`。R では C API にしかありません): フィクスチャは R の出力ではなく、512 ビットの Rmpfr で計算した正しく丸めた値で、許容誤差 1e-14 で比較します (観測された最大の誤差は `lgamma1p` の 1.7e-15)。6 つのケースは oracle が 512 ビットで計算できる範囲を超えており、フィクスチャの値が誤っています: `lgamma1p(±1e-300)` (フィクスチャは 0。1 + x が 1 に丸まる)、x = 700、708、745 の `log1mexp(x)` (フィクスチャは 0。1 − exp(−x) が 1 に丸まる)、`log1pexp(1e300)` (フィクスチャは Inf。exp(1e300) が MPFR でオーバーフローする)。これらは代わりに展開の主要項 −γx、−exp(−x)、x と照合します。
- **線形代数:** `solve` と行列式には、gmp の有理数で計算した厳密な参照値があります (どの double も有理数で正確に表せます)。分解はそうではなく、後退誤差と直交性で確かめます (下記参照)。

## 許容誤差

| 分野 | 相対許容誤差 |
|---|---|
| 特殊関数、密度関数、分布関数 | 1e-14 (非心 t: 1e-13、`ptukey`: 2e-14) |
| base R にない分布 (逆ガンマ、Kumaraswamy、Pareto、三角、Laplace、逆正弦) | d/p/q は 1e-14。extraDistr (逆正弦は R の beta(1/2, 1/2) を (a, b) に移したもの) と mpmath に対して |
| 分位点関数 | 1e-14、または後退誤差が R 以下。離散分布の分位点は完全一致か定義による検証 |
| 乱数 | 離散値、`sample`、`r2dtable` は完全一致。連続値は 1e-12 以内。消費した一様乱数の個数を厳密に確かめる |
| 記述統計 | 1e-14 (打ち消し合いから決まる 0 に近い歪度と尖度は絶対誤差で測る) |
| 仮説検定 | すべての数値フィールドで 1e-12 (`cor`: 1e-15、`pAdjust`: 完全一致。`ansariTest` の正規近似の区間など、許容誤差 1e-4 の `uniroot` で求める根: 1e-4)。テキストフィールドは完全一致 |
| 線形モデル (`lm`、`confint`、`predict`) | すべての数値フィールドで 1e-12 |
| 線形代数 | 1e-14 (`crossprod`、`norm`、`backsolve`、`chol`、`qr`、`svd` による 2-ノルム、行列演算、`seq`、`lu`) または 1e-13 (`solve`、`determinant`、`rcond`、`svd`、`kappa`、`ginv`、`eigen`)。結果のノルムに対する相対値で測る。`prcomp` は 1e-12。ピボット、ランク、行列式の符号は完全一致 |
| 数値計算 | 1e-15 (`approx`)、1e-14 (`integrate`、`optimize`、`uniroot`、`barylag`、`hermiteInterp`、`ode`、および絶対誤差の下限 1e-12 付きの `grad`、`jacobian`、`hessian`)、1e-13 (`spline`、`splinefun`、`splinefunH`) |

許容誤差は分野ごとに実測をもとに決めました。R または参照値に対して観測された最大の誤差は、許容誤差をわずかに下回っています。

### 一部の許容誤差が広い理由

- **`ptukey` (2e-14):** R の `ptukey` の精度は約 8 桁なので、ほぼすべてのケースを参照値と比べます。参照値は 160 ビットの台形公式で、刻み幅を半分にしたときの値の変化が 1e-18 未満だった場合だけ使います。誤差のほとんどは 6e-15 未満で、最大は `ptukey(0.5, 1000, 10)` ≈ 1.3e-129 での 1.7e-14 です。ここでは log W の丸め (ε |log W|) が支配的です。
- **非心 t (1e-13):** P[T ≤ t] = E[Φ(tS − δ)] を台形公式で積分します。深い裾 (1e-50 未満) では節点での指数が数百になり、参照値に対する誤差が 1e-13 に近づきます (中心付近では約 1e-15)。

### 乱数

`Math.log`、`Math.exp`、`Math.pow`、`Math.tan` の最後の数ビットが V8 と glibc の libm で異なるため、連続値は完全には一致しません。観測された最大の差は 1.2e-13 で、shape がごく小さい (例: 0.001) ガンマ乱数で生じます。そこでは exp(log(u)/shape) が誤差を 1/shape 倍に拡大します。一様乱数の個数は、各ケースの後に `runif(1)` を引いて確かめます。採択・棄却の判定が 1 回でも異なれば、そこに現れます。

### 仮説検定

- テキストフィールド (`method`、統計量の名前など) は完全に一致しなければなりません。R がエラーを出す入力では、エラーを投げなければなりません。
- 桁落ちで決まるフィールドは、スケールの下限を設けて |差| / max(|期待値|, scale) で測ります。t 検定の信頼区間では |mu| を、Wilcoxon の信頼区間と推定値では、データの絶対値の最大と |mu| (真の根が 0 のとき) を使います。
- 3 × 3 以上の表に対する Fisher の検定は、妥当な時間で参照値を求められないため、そこでの相対差 1e-10 までは既知の差異として記録します。
- `ansariTest` の正規近似の限界と推定値は、R でも rStats.js でも許容誤差 1e-4 の `uniroot` で求めた根なので、許容誤差 1e-4 で比較します。同じ根の探索を同じ階段関数に対して行うので、R とは 3e-15 以内で一致します。R が "object 'cint' not found" で失敗するケース (24 件、[differences-from-r.md](differences-from-r.md) を参照) は、oracle が `exact = FALSE` で繰り返したケースと比較します。
- シミュレーションによる p 値 (`chisqTestSim`、`fisherTestSim`) は完全に一致しなければなりません。各ケースは検定の直前に `setSeed(seed)` を呼び、その後に引く `runif(1)` が R と等しいことで、消費した一様乱数の個数を確かめます。
- `chisqTest(x, y)` は水準をコードポイント順に並べますが、R はロケールの照合順序を使いました。順序が異なるフィクスチャの 1 ケースでは、R の行と列を並べ替えてから比較します。

### 線形代数

- 行列とベクトルはノルムで比較します (|差| / そのフィールドの絶対値の最大)。0 に近い要素は桁落ちで決まるため、要素ごとには比較できません。`crossprod` は列ノルムの積をスケールに使います。
- **条件数によるスケーリング。** R は OpenBLAS を使っており、演算の順序が rStats.js と異なります。丸めの違いは条件数 κ とともに大きくなり、oracle はこれを `args.cond` に保存します。許容する誤差は scale × max(tolerance, 10 ε κ^k) で、k は既知の感度から決めます。`chol` は 1/2、`solve`、行列式、`rcond`、`kappa`、`qr`、`ginv` は 1、最小二乗の係数 (`qrCoef`、`qrSolve`) は 2 です。最小二乗の係数は、残差が 0 でないとき誤差が κ² に比例するためです。
- **固有ベクトルと特異ベクトル**は、符号 (複素ベクトルでは位相) をそろえてから比較します。その誤差は ε × 最大の値 / 値の間隔 に比例するため、oracle が保存した最小の相対間隔 (`gap`) で許容誤差を広げます。重複した値 (相対間隔が 1e-8 未満) と 0 の特異値に対するベクトルは一意に定まらないので、比較しません。
- **列が従属している `qr`:** 数値ランク (最大の特異値の 1e-13 倍を超える特異値の個数) より後ろの列の Householder ベクトルは丸めだけで決まるため、比較しません。LAPACK モードでランク落ちした行列では、Q、`qty`、`qy`、係数も比較しません。
- **不変量。** すべての分解について、後退誤差と直交性 (‖A − QR‖、‖UDVᵀ − A‖、‖QᵀQ − I‖ など、10 × 次元 × ε 以内) を `test/linalg-invariants.test.ts` で確かめます。
- `qr` と `chol` のピボットとランクは、R の限定的な列ピボット選択も含めて R と完全に一致します。
- OpenBLAS のバージョンが違うと最後の数ビットが変わりうるため、線形代数のフィクスチャには、R が使った LAPACK と BLAS のバージョンを `info` ブロックに記録しています。

## 既知の精度の問題

テストしている範囲では、既知の問題はありません。すべてのケースが、許容誤差の範囲で R または高精度の参照値と一致します。

その範囲の外では、次数が数千で x < ν の `besselJ` と `besselY` の相対誤差が 1.0〜1.5e-14 ほどになります (たとえば `besselY(3000, 3949)` で 1.04e-14、`besselJ(1000, 1500)` で 9.9e-15)。漸化式と連分数の多数のステップで丸め誤差が積み重なるためです。

R の `qnbinom` は 13 個の入力で終了しません (例: `qnbinom(-1, 0.5, 1e-10, log.p = TRUE)`)。`oracle/nbinom.R` は各ケースを 2 秒に制限し、それらの行をフィクスチャから外します。

## 精度を支える工夫

ほとんどのカーネルは SciPy の xsf (BSD-3) と Boost.Math (BSL-1.0) から移植しています。線形代数は LAPACK のリファレンス実装 (修正 BSD)、LINPACK、EISPACK (パブリックドメイン) に従っています。[THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md) を参照してください。R に並ぶ、または R を上回るために加えた主な変更は次のとおりです。

- **指数を double-double で。** exp(−E) として計算した確率の相対誤差は、E の絶対誤差に等しくなります。E が数百 (確率が 1e-300 付近) になると、double 精度だけでは誤差が 1e-13 に達します。Loader の鞍点項 (`src/special/loader.ts`) と、指数分布、Weibull 分布、ロジスティック分布、対数正規分布における exp(−t) の引数 (`src/internal/ddexp.ts`) は double-double で組み立てます。t = 700 では t の丸めだけで 6e-14 の誤差になります。
- **x と 1 − x を厳密な組として。** 丸めた 1 − x に大きな指数 (b = 1e5) を掛けると、その丸め誤差が拡大されます。不完全ベータ関数は 2 つのうち小さいほうから計算し、もう一方を double-double で組み立てます。t 分布と F 分布は n/(n + t²) などの量を double-double で渡します。
- **連分数を double-double で** (`src/special/incbet.ts`)。パラメータが大きく x が平均に近いとき、連分数は x の丸めにきわめて敏感です (a = 1e5, x = 0.999 で 6e-13)。係数の a + b と b − 1 も double-double にします。a + b を丸めると小さい b の桁が失われるためです (a = 1e8, b = 0.01 で 5e-11)。2^52 以上では 1 の刻みが失われるので、すべての係数を double-double にします。
- **両側の裾をそれぞれ直接計算し**、決して 1 − (反対側の裾) としては求めません。級数の補数 1 − I_x(a, b) には引き算を含まない式を使います。
- **lgamma(b + a) − lgamma(b) を引き算なしで** (`src/special/lgammaDiff.ts`)。a ≪ b のときに使い、`lbeta`、前置因子、級数の補数で利用します。lgamma の零点 (1 と 2) の近くでは lgamma1p を使います (xsf の式は x = 1 + 1e-10 で相対誤差 6e-7 になります)。
- **分位点のソルバー** (`src/internal/invert.ts`)。u = log x で Newton/Halley 反復を行い、|log x| が大きいときは x そのもので仕上げます (そのときは u での刻みが x の精度を制限するため)。丸めのために動かない刻みは収束とみなします。`qlnorm` は、z の丸めが sdlog |z| 倍に拡大されるため、正規分布の分位点に double-double の Newton 補正を 1 回かけます。`qgeom` は閉じた式を使います。離散分布の二分探索は、答えが 2^53 を超えたら止めます。
- **`pnorm` の裾**では、exp(−q²/2) を正確に計算するために q = hi + lo (hi は 1/16 刻みの格子上) に分けます。`logP` が −2048 未満 (Cephes の裾の近似の範囲外) の `qnorm` は、`pnorm` を使った Newton ステップを 1 回加えます。
- **Wilcoxon の順位和**は Harding (1984) の q-二項積を double-double で使います。double 精度では m = n = 150 で 1e-13 ずれます。
- **スチューデント化された範囲**は Copenhaver と Holland の二重積分を、適応的 Clenshaw–Curtis 求積で計算します。外側の積分は v = log(t/a) で行い、上側確率は直接積分します。
- **非心分布** (`src/internal/poissonMixture.ts`)。ポアソン混合は最頻値から外側へ向かって正の項だけで合計し、漸化式は double-double で、指数は別に保持します (仮数 × 2^(500k))。そのため対数での答えは 1e-300 未満でも正確です。非心 t は、片側の二重指数型の変数変換を施したあとの正の被積分関数を積分するので、t と δ の符号が逆でも桁落ちが起きません。遠い裾では部分積分した形を使い、さらに先では |t|^(−ν) のべき乗則を使います。非心カイ二乗分布の密度は、x × ncp が非常に大きいときベッセル関数の漸近展開を使います。
- **検定のための和** (`src/internal/summary.ts`)。平均、分散、相関は double-double で合計し、偏差は掛け算の前に 2 のべき乗で尺度を変えるので、1e±200 付近のデータでもオーバーフローもアンダーフローもしません。

これにかかる速度面のコストと、double-double の効果を測る方法は [performance.md](performance.md) で説明しています。
